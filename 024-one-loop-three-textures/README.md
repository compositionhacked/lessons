# Lesson 024 · One loop, three textures

[Download MIDI](024-demonstration.mid) · [Download MP3](024-demonstration.mp3)

90 BPM · 4/4 · E Dorian

Play Em–F♯m–Em | A–G/A–A. Hold E2 in bar 1 and A2 in bar 2. The upper voicings are E3–G3–B3, F♯3–A3–C♯4, A3–C♯4–E4 and G3–B3–D4. Each neighbor enters on beat 3 and the original voicing returns on beat 4. The demonstration uses arpeggios, offbeat hits and clipped eighth notes to make the same loop feel like different sections.

Import the MIDI into Ableton at 90 BPM and assign a guitar sound and bass sound.

## Writing exercise

Write eight bars on the loop. Use arpeggios for bars 1–4 and offbeat chord hits for bars 5–8. Keep every chord change in the same place.
