# Lesson 049 — Put the dyad between the beats

## Hear one change
Keep the bass on beats 1 and 3. In A, the upper pairs enter on beats 1, 2, 3 and 4. In B, the first three bars enter on each &. The fourth bar lands on G on beat 1 in both versions, followed by shorter answers. Same pitches, timbres, bass and pulse; the upper attack times change.

In B, bars 1–3 attack at beats 1&, 2&, 3&, 4&. Their durations are 1, 0.5, 1 and 0.5 beats: release at beat 3 before the next offbeat. Bar 4 attacks at beats 1, 2&, 3& and releases at beats 2, 3, 4. A uses the same durations but attacks bars 1–3 on beats 1, 2, 3, 4. The bass plays root notes on beats 1 and 3 for 0.75 beat each. No constant pedal is added across changing roots.

## Write
Compose a new four-bar response over G | C | D | G. Use three dyads and a single-note ending. Retain their pitch order and change only entry times. Record two takes: on the beat, then between the beats. Keep the version that answers the bass clearly. The supplied four-bar loop demonstrates the device; it is not a completed version of this assignment and is not the complete eight-bar source etude.
