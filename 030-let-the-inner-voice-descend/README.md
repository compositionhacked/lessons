# Lesson 30 — Let the inner voice descend.

**Album study:** Dire Straits, *Communiqué* (1979) · **Song reference:** “News” · **Tempo:** 82 BPM · **Meter:** 4/4 · **Tuning:** standard guitar tuning.

> This is an original composition exercise about a device heard in the album. The audio is synthesized for teaching; it is not an album recording or a transcription. The eight-bar study is repeated once in the Reel.

## The device

Keep one upper note common while the inner line moves by step. The same pitch changes function as the bass and chord change; play the inner note quieter than the melody.

## Eight-bar harmony

F#m · Dmaj7/F# · Bm7/F# · C#7 · F#m · A/E · Dmaj7 · C#7

## Writing assignment

Write an eight-bar chord sequence with a held soprano. Compose the inner line first; let it descend by step, and name its function over every chord.
