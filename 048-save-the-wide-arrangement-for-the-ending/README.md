## Write eight bars

Write eight bars in A. In bars 1–4, use restrained three-note upper chords and one sustained melody note per bar. In bars 5–8, widen the register or add a complementary sustained voice without increasing the attack rate. Use C♯ as a real shared tone across Dmaj7 and C♯m7, and let E7sus4 resolve to the ending A chord.
