# CompositionHacked


Learn how music is built. Hear a device, understand what it changes, then write something with it.


Every published lesson has an original MP3 demonstration, editable MIDI and a practical writing exercise. No original album recordings are distributed here.

## How to use the files


Listen to the MP3 first. Import the MIDI into Ableton Live or another DAW, assign your own instruments, and change one thing at a time. The musical information is in the MIDI; the exact sound depends on your instrument choices.


On mobile, open a download link and save the file. On a GitHub file page, use **Download raw file** if your browser does not start the download directly.
