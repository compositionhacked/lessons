# CompositionHacked publishing standard

Every lesson should give the learner something they can hear, inspect and change.

Before a Reel is published:

1. Explain one practical compositional move, including which notes change and why the change matters in its musical context.
2. Make an original audio demonstration with a fair comparison: keep tempo, rhythm and instrumentation consistent while isolating the device.
3. Publish an editable `.mid` and a corresponding `.mp3` in a numbered lesson folder.
4. Include a short README with tempo, meter, note or chord map, file instructions and a specific writing exercise.
5. Add the lesson to the root index. Put its number and GitHub download address in the Instagram caption. Use the repository index as the channel's permanent profile link.
6. Open the public lesson and verify that both downloads are present before sharing the post.

Use stable folder names such as `001-one-bass-three-worlds`. Keep old download paths working when adding future lessons.

The tone is practical and curious. Explain the cause of the sound in plain language, then ask the learner to make a musical choice. Give the lesson depth through listening, comparison and writing.
